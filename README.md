# আমার লেখালেখি — ব্যক্তিগত লেখা ও ভিডিও ওয়েবসাইট

Next.js + Prisma (SQLite) + JWT admin auth দিয়ে বানানো একটা full-stack ওয়েবসাইট, যেখানে আপনি
ছোট গল্প, কবিতা, উপন্যাস পোস্ট করতে পারবেন এবং সরাসরি নিজের সার্ভারে ভিডিও ফাইল আপলোড করতে পারবেন।

## পেজ লিস্ট

- হোম (`/`)
- আমার সম্পর্কে (`/about`)
- ছোট গল্প (`/chuto-golpo`)
- কবিতা (`/kobita`)
- উপন্যাস (`/uponnash`)
- ভিডিও (`/videos`) — অতিরিক্ত যোগ করা হয়েছে, যেহেতু ভিডিও এই সাইটের মূল ফিচার
- Admin লগইন (`/admin/login`)
- Admin ড্যাশবোর্ড (`/admin/dashboard`) — পোস্ট ও ভিডিও ম্যানেজমেন্ট
- ফুটার (সব পেজে থাকে)

## ফিচারসমূহ

- পোস্ট তৈরি/এডিট/ডিলিট (ছোট গল্প, কবিতা, উপন্যাস — ক্যাটাগরি অনুযায়ী)
- ড্র্যাফট/পাবলিশ টগল
- সরাসরি সার্ভারে ভিডিও ফাইল আপলোড (progress bar সহ), ডিলিট করলে ফাইলও মুছে যায়
- JWT + httpOnly cookie দিয়ে Admin auth (একজন অ্যাডমিন, `.env` এ ইউজারনেম/পাসওয়ার্ড)
- বাংলা ফন্ট (Hind Siliguri), মোবাইল-ফ্রেন্ডলি ডিজাইন (Tailwind CSS)

## লোকাল সেটআপ

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল করুন (Node.js 18+ দরকার)
npm install

# ২. .env ফাইল বানান
cp .env.example .env
# এরপর .env ফাইল খুলে JWT_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD বদলে দিন

# ৩. ডেটাবেজ তৈরি করুন
npx prisma db push

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

এরপর ব্রাউজারে যান: http://localhost:3000
Admin লগইন: http://localhost:3000/admin/login (`.env` এ দেওয়া ইউজারনেম/পাসওয়ার্ড দিয়ে)

## প্রোডাকশনে ডিপ্লয় করার আগে জরুরি নোট

১. **Vercel এ ডিপ্লয় করবেন না (বা সাবধানে করুন)।**
   Vercel সার্ভারলেস — এখানে ফাইল সিস্টেমে লেখা যেকোনো ফাইল (আপনার আপলোড করা ভিডিও)
   প্রতিটা নতুন ডিপ্লয়মেন্টে হারিয়ে যাবে, এবং রিকোয়েস্ট বডি সাইজেও লিমিট আছে (৪.৫MB এর মতো)।
   এই সাইটের জন্য একটা **VPS (যেমন DigitalOcean, Hetzner, Contabo)** অথবা persistent disk
   সাপোর্ট করে এমন হোস্টিং (Railway, Render — volume/disk অ্যাড করে) ব্যবহার করা ভালো।

২. **VPS এ ডিপ্লয় করার সাধারণ ধাপ:**
   ```bash
   npm install
   npx prisma db push
   npm run build
   npm run start   # অথবা pm2 দিয়ে চালান: pm2 start npm --name lekhalekhi -- start
   ```
   এরপর Nginx দিয়ে রিভার্স প্রক্সি করে ডোমেইন যুক্ত করুন এবং Let's Encrypt দিয়ে SSL সেটআপ করুন।

৩. **`.env` ফাইলটা কখনো পাবলিক রিপোতে দেবেন না** — এতে আপনার admin পাসওয়ার্ড আছে।

৪. **নিয়মিত ব্যাকআপ নিন**: `prisma/dev.db` (সব পোস্ট/ভিডিও তথ্য) এবং `public/uploads/` ফোল্ডার
   (আসল ভিডিও ফাইলগুলো) — এই দুটো ফোল্ডার/ফাইল ব্যাকআপ রাখলে ডেটা হারানোর ভয় থাকবে না।

৫. ভিডিওর সংখ্যা/সাইজ বাড়তে থাকলে ভবিষ্যতে চাইলে Cloudflare R2 / AWS S3 এর মতো অবজেক্ট
   স্টোরেজে সরিয়ে নেওয়া যায় — এখনকার কোড লোকাল ডিস্কে সেভ করে, যা ছোট থেকে মাঝারি সাইজের
   সাইটের জন্য যথেষ্ট।

## প্রজেক্ট স্ট্রাকচার (সংক্ষেপে)

```
app/(site)/        →  পাবলিক পেজসমূহ (হোম, about, গল্প/কবিতা/উপন্যাস, ভিডিও)
app/admin/          →  admin login ও dashboard
app/api/             →  posts ও videos এর জন্য API রুট
components/          →  React কম্পোনেন্ট (Header, Footer, ফর্ম, কার্ড ইত্যাদি)
lib/                 →  prisma client, auth হেল্পার, slug হেল্পার
prisma/schema.prisma →  ডেটাবেজ স্কিমা (Post, Video)
public/uploads/      →  আপলোড করা ভিডিও ফাইল এখানে সেভ হয়
```
